# OPEN WORLD metatiles: 16x16 each, quarters TL TR BL BR become four 8x8 BG tiles.
# Identical 8x8 tiles are stored once, so reuse quarters freely.
#
#   o = colour 0  LIGHT  (fire, beacon light, glints, the Heart) -- use sparingly on land
#   . = colour 1  ground
#   + = colour 2  detail
#   # = colour 3  deep shadow / silhouette
#
# pal= CGB palette class: GRASS FOREST WATER SAND SNOW ROCK LIGHT SKY; pals= per quarter.
# anim=CORNER:NAME puts the animated tile NAME in that quarter (its pixels here are ignored,
# but draw frame 0 there anyway so the source reads right).
@chars o=0 .=1 +=2 #=3
